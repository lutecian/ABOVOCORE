# ABOVOCORE Platform

AI-Powered Business Acquisition & Portfolio Management Platform.

## Architecture Overview

This is a modular monorepo containing the core components of the AbovoCore acquisition infrastructure.

## Repository Structure

- `apps/`: Deployable applications (Web, API, Worker, Admin).
- `packages/`: Shared libraries and core engines (Financial, AI Gateway, etc.).
- `agents/`: AI agent definitions and orchestration logic.
- `infrastructure/`: IaC and deployment configurations.
- `documentation/`: Project documentation and specifications.
